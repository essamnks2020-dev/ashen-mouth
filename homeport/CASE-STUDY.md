# Homeport — case study

## Problem

Electronic logbooks are becoming mandatory across New England / Mid-Atlantic / proposed Gulf & Atlantic.
Existing apps optimize for **the regulator**. Fishermen still run profit math on scraps of paper.

## Insight

Compliance is table stakes. The unpaid job is: *where do I land, and what did I actually clear after fuel and crew?*

## Solution

Homeport is a local-first mobile logbook:

1. Log haul by species/weight
2. Auto-calc skipper share after fuel, ice, crew %
3. Compare dock prices + steam cost before you commit
4. Watch quota pressure before you ride the cap

## Why it wins with no capital

| Idea | Blocker without capital |
| --- | --- |
| FieldLedger marketplace | Chicken-egg farms ↔ buyers |
| VetRelay network | Licensed vets + coverage density |
| Executor OS | Funeral-home distribution |
| Birth Claims | Insurance ops expertise + practice sales |
| **Homeport** | **None — solo value on day one** |

## Monetization sketch (later)

- Free offline core
- Pro: multi-vessel, CSV export, dock alert push (~$8–12/mo)
- Co-op license for fleets

## Status

Shipped as a portfolio-grade interactive prototype. No backend. Data stays on-device.
