# THRESHOLD — Case study

## Problem

People don't fail mornings because they lack a todo app. They fail the **last thirty seconds** — keys, umbrella, leave-by math, "is it raining *there*?" — while already half out the door.

Calendars show the meeting. Weather apps show one zip code. Checklists are forever-lists that don't know Tuesday is gym day.

## Insight

Departure is a **ritual**, not a queue. The product should feel like crossing a threshold: home air → destination air → what you need → seal.

## Solution

**Threshold** is a local-first mobile ritual:

- Weather **home vs destination** (on-device sketch today; swap for Open-Meteo later)
- **Leave-by** from next event + travel + buffer
- Checklist filtered by **weekday** and **weather** (umbrella only when wet)
- A door that **opens and seals** the departure into history

No account. No backend. Works offline in the hallway with one bar of signal.

## Why it's school / portfolio ready

- Clear human problem, daily use
- Interaction craft (atmosphere, door, sound) without gimmick drowning function
- Honest scope: one moment, done well

## Monetization path (later)

Optional iCloud sync, live weather, calendar OAuth — never required for the core ritual.
