# Essam — Portfolio

Interaction craft: daily rituals and games with mechanics you can feel.

## Run

```bash
node serve.mjs                 # http://localhost:5173
```

| Path | What |
| --- | --- |
| `/` | Portfolio |
| `/threshold/` | **THRESHOLD** — departure ritual (lead) |
| `/ashen-mouth/` | ASHEN MOUTH — listening-horror game |
| `/homeport/` | Homeport — archive craft study |
| `/temper/` | TEMPER — archive interaction study |

Nothing to install. Node ≥ 18.

## Projects

### Threshold (lead)
The last thirty seconds before you leave. Destination weather, leave-by, day-aware checklist, door seal.
Docs: `threshold/README.md` · `threshold/DESIGN.md` · `threshold/CASE-STUDY.md`

### ASHEN MOUTH
First-person WebGL horror. Silence is stealth. Whisper **MAREN** at the grate.
Docs: `ashen-mouth/README.md` · `ashen-mouth/DESIGN.md`

### Archive
Homeport and TEMPER remain playable as craft studies; Threshold is the daily-life school lead.
