# Essam — Portfolio

Interaction craft: games and utilities with mechanics you can feel.

## Run

```bash
node serve.mjs                 # http://localhost:5173
```

| Path | What |
| --- | --- |
| `/` | Portfolio |
| `/ashen-mouth/` | ASHEN MOUTH — listening-horror game |
| `/temper/` | TEMPER — message cooling forge |

Nothing to install. Node ≥ 18.
