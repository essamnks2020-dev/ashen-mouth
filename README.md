# Essam — Portfolio

Interaction craft: games and utilities with mechanics you can feel.

## Run

```bash
node serve.mjs                 # http://localhost:5173
```

| Path | What |
| --- | --- |
| `/` | Portfolio |
| `/homeport/` | Homeport — fishing logbook (profit, docks, quota) |
| `/ashen-mouth/` | ASHEN MOUTH — listening-horror game |
| `/temper/` | TEMPER — message cooling forge |

Nothing to install. Node ≥ 18.

## Projects

### Homeport
Offshore-first fishing logbook. Profit after fuel & crew. Dock prices. Quota warnings.

### ASHEN MOUTH
First-person WebGL horror. Silence is stealth. Whisper **MAREN** at the grate.

### TEMPER
Local-first message forge. Cool heated text before you send it. Case study in-app.
