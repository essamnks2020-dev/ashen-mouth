# Outset — Design

## Feeling

Morning light on a stoop. Milk sky. One leaf of sage green. Calm enough to use every day — not a dark gothic ritual.

## Palette (few colors)

| Token | Hex | Role |
| --- | --- | --- |
| Milk | `#fbf8f2` | Surfaces |
| Ink | `#1c2a22` | Type |
| Sage | `#5b8a72` / `#3f6b4f` | Brand, CTAs, progress |
| Sun | `#f0c56a` | Soft highlight only |
| Warn | `#c4784a` | Late states only |

## Type

- **Fraunces** — brand + display
- **Manrope** — UI

## Motion

- Screen enter: rise + soft blur
- Cover float + logo pulse
- Countdown conic ring
- Check spring pop
- Door leaf swing + burst on seal
- Atmosphere: pollen motes, drifting leaves, rain when wet
- Respect `prefers-reduced-motion`

## Logo / cover

Arch doorway + leaf + sun glow on milky field. Rounded app icon. Wide cover for portfolio/og.
